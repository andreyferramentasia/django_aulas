Um app é uma parte do projeto com uma função específica (cursos, usuários, pagamentos...). Um projeto pode ter vários apps.

> python manage.py startapp courses  # troque courses pelo nome do seu app

Dica

Minúsculas, sem espaços ou acentos, de preferência no plural: courses, students.

O app do tutorial

Daqui em diante o exemplo é um cadastro de cursos, num app chamado courses. Se o seu app tiver outro nome, troque courses pelo nome dele onde o código mostrar o comentário # troque courses pelo nome do seu app. Nos blocos de código, o nome do app aparece em amarelo.

? O que é cada arquivo

models.py
Tabelas do banco de dados, escritas como classes Python.
views.py
Lógica das páginas, recebe a requisição e devolve a resposta.
admin.py
Registra os models para aparecerem no painel /admin.
apps.py
Configuração do app (nome, rótulo).
tests.py
Testes automatizados do app.
migrations/
Histórico das alterações no banco, gerado pelo makemigrations.
__init__.py
Indica ao Python que a pasta é um pacote. Fica vazio.

Atenção

O startapp não cria urls.py nem a pasta templates/, eles são criados manualmente quando necessário.
