A DeleteView é a view genérica de exclusão: busca o registro pelo pk, mostra uma página de confirmação e só apaga quando o usuário confirma.

1 A view

from django.views.generic import ListView, CreateView, UpdateView, DeleteView
...


class CourseDeleteView(DeleteView):
    model = Course
    # troque courses pelo nome do seu app
    template_name = "courses/course_confirm_delete.html"
    context_object_name = "course"
    success_url = reverse_lazy("courses:course_list")
Sem form_class
Excluir não tem campos para preencher, então não usa formulário.
course_confirm_delete.html
Página que pergunta "tem certeza?". Abrir o link não apaga nada, só o post do botão apaga.

2 A rota

from django.urls import path
# troque courses pelo nome do seu app
from courses.views import CourseListView, CourseCreateView, CourseUpdateView, CourseDeleteView

app_name = "courses"

urlpatterns = [
    path("listar/", CourseListView.as_view(), name="course_list"),
    path("criar/", CourseCreateView.as_view(), name="course_create"),
    path("<int:pk>/editar/", CourseUpdateView.as_view(), name="course_update"),
    path("<int:pk>/deletar/", CourseDeleteView.as_view(), name="course_delete"),
]

Atenção

Excluir um curso não apaga o professor. O contrário apaga: o Course aponta para Person com on_delete=models.CASCADE, então excluir uma pessoa no admin apaga também os cursos dela. Se trocar para PROTECT, o Django não deixa excluir quem tem cursos.

E os arquivos?

Excluir o curso apaga o registro do banco, mas o material e a imagem continuam na pasta media/. O Django não apaga arquivos sozinho.

A DeleteView do passo anterior precisa de uma página que pergunta "tem certeza?", e a lista precisa de um botão para chegar nela.

1 A página de confirmação

{% extends "base.html" %}

{% block title %}Excluir curso{% endblock %}

{% block content %}
    <h1>Excluir {{ course }}?</h1>
    <form method="post">
        {% csrf_token %}
        <button type="submit" class="btn btn-danger">Excluir</button>
    </form>
{% endblock %}

2 Link de exclusão na lista

No course_list.html, ao lado do Editar:

{% for course in courses %}
    <li>
        {{ course.name }}
        {# troque courses pelo nome do seu app #}
        <a href="{% url 'courses:course_update' course.pk %}" class="btn btn-sm btn-primary">Editar</a>
        <a href="{% url 'courses:course_delete' course.pk %}" class="btn btn-sm btn-danger">Excluir</a>
    </li>
{% empty %}
    <li>Nenhum curso cadastrado.</li>
{% endfor %}
method="post"
Só o envio do formulário apaga. Abrir a página pelo link (um get) apenas mostra a pergunta.
{% csrf_token %}
Obrigatório aqui também, mesmo sem campos: sem ele o Django responde 403.
course.pk
Mesma ideia do Editar: dentro do for, cada linha gera o link do seu próprio curso.

✓ Resultado esperado

Na lista, clique em Excluir, confirme em Excluir e volte para a lista sem aquele curso.
