A DeleteView é a view genérica de exclusão: busca o registro pelo pk, mostra uma página de confirmação e só apaga quando o usuário confirma.

1 A view

from django.views.generic import ListView, CreateView, UpdateView, DeleteView
...


class PersonDeleteView(DeleteView):
    model = Person
    template_name = "nome_do_seu_app/person_confirm_delete.html"
    context_object_name = "person"
    success_url = reverse_lazy("nome_do_seu_app:person_list")
Sem form_class
Excluir não tem campos para preencher, então não usa formulário.
person_confirm_delete.html
Página que pergunta "tem certeza?". Abrir o link não apaga nada, só o post do botão apaga.

2 A rota

from django.urls import path
from nome_do_seu_app.views import PersonListView, PersonCreateView, PersonUpdateView, PersonDeleteView

app_name = "nome_do_seu_app"

urlpatterns = [
    path("pessoas/", PersonListView.as_view(), name="person_list"),
    path("pessoas/nova/", PersonCreateView.as_view(), name="person_create"),
    path("pessoas/<int:pk>/editar/", PersonUpdateView.as_view(), name="person_update"),
    path("pessoas/<int:pk>/excluir/", PersonDeleteView.as_view(), name="person_delete"),
]

Atenção

O Course aponta para Person com on_delete=models.CASCADE: excluir um professor apaga também os cursos dele. Se trocar para PROTECT, o Django não deixa excluir quem tem cursos.

Documentação

docs.djangoproject.com/pt-br/stable/ref/class-based-views/generic-editing

A DeleteView do passo anterior precisa de uma página que pergunta "tem certeza?", e a lista precisa de um botão para chegar nela.

1 A página de confirmação

{% extends "base.html" %}

{% block title %}Excluir pessoa{% endblock %}

{% block content %}
    <h1>Excluir {{ person }}?</h1>
    <form method="post">
        {% csrf_token %}
        <button type="submit" class="btn btn-danger">Excluir</button>
    </form>
{% endblock %}

2 Link de exclusão na lista

No person_list.html, ao lado do Editar:

{% for person in people %}
    <li>
        {{ person.first_name }} {{ person.last_name }}
        <a href="{% url 'nome_do_seu_app:person_update' person.pk %}" class="btn btn-sm btn-primary">Editar</a>
        <a href="{% url 'nome_do_seu_app:person_delete' person.pk %}" class="btn btn-sm btn-danger">Excluir</a>
    </li>
{% empty %}
    <li>Nenhuma pessoa cadastrada.</li>
{% endfor %}
method="post"
Só o envio do formulário apaga. Abrir a página pelo link (um get) apenas mostra a pergunta.
{% csrf_token %}
Obrigatório aqui também, mesmo sem campos: sem ele o Django responde 403.
person.pk
Mesma ideia do Editar: dentro do for, cada linha gera o link da sua própria pessoa.

✓ Resultado esperado

Na lista, clique em Excluir, confirme em Excluir e volte para a lista sem aquela pessoa.
