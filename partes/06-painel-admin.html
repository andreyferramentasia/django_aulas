Para os models aparecerem no /admin, registre-os no admin.py do app:

from django.contrib import admin
from courses.models import Person, Course  # troque courses pelo nome do seu app


class PersonAdmin(admin.ModelAdmin):
    list_display = ("first_name", "last_name")
    search_fields = ("first_name", "last_name")


class CourseAdmin(admin.ModelAdmin):
    list_display = ("name", "teacher", "workload", "period")
    search_fields = ("name",)
    list_filter = ("teacher", "period")


admin.site.register(Person, PersonAdmin)
admin.site.register(Course, CourseAdmin)

? Entendendo o código

ModelAdmin
Classe que configura como o model aparece no admin.
list_display
Colunas exibidas na listagem.
search_fields
Campos usados na barra de busca.
list_filter
Filtros na lateral da listagem.
admin.site.register
Liga o model à sua configuração no admin.

Atenção

Tuplas com um item precisam de vírgula: ("name",). Sem ela, o Django dá erro.

Import absoluto

Use o nome do app, o mesmo do name em apps.py: from courses.models import .... Fica claro de onde vem cada classe.
