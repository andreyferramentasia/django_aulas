O que acontece?

São criadas no db.sqlite3 as tabelas de usuários, sessões e do admin.

> python manage.py createsuperuser
Username (leave blank to use 'andrey'): admin
Email address: admin@admin.br
Password: # nada aparece ao digitar
Password (again): # nada aparece ao digitar
The password is too similar to the email address.
Bypass password validation and create user anyway? [y/N]: y
Superuser created successfully.
  1. Username: nome de acesso.
  2. Email: precisa ter formato de e-mail, com @ e terminando em .com ou .br.
  3. Password: senha e confirmação.

A senha não aparece

Ao digitar a senha, nada é exibido no terminal. É normal, digite e pressione Enter.

Senha fraca?

O Django avisa quando a senha é fraca, por exemplo:

  • The password is too similar to the email address. (parecida com o e-mail)
  • This password is too short. (curta demais)
  • This password is too common. (comum demais)

Em seguida pergunta Bypass password validation and create user anyway? [y/N]:

  • y (yes): cria o usuário mesmo assim.
  • N (no): cancela e pede a senha novamente. É o padrão ao apertar só Enter.

Em desenvolvimento, pode usar y. Em produção, use uma senha forte.

  1. Rode o servidor: python manage.py runserver
  2. Acesse http://127.0.0.1:8000/admin e entre com o usuário criado.

1 Registrar o app

No arquivo app/settings.py, adicione 'jazzmin' no topo do INSTALLED_APPS:

INSTALLED_APPS = [
    'jazzmin',
    'django.contrib.admin',
    'django.contrib.auth',
    'django.contrib.contenttypes',
    'django.contrib.sessions',
    'django.contrib.messages',
    'django.contrib.staticfiles',
]

Atenção

Não esqueça a vírgula depois de 'jazzmin'. Ele precisa vir antes do django.contrib.admin.
