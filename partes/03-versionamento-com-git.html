Dica

Feche e abra o terminal novamente após instalar.

  1. No GitHub, clique na sua foto (canto superior direito) e vá em Repositories.
  1. Clique em New.
  1. Preencha o Repository name * (campo obrigatório).

+ Adicionar colaboradores (opcional)

Para outra pessoa enviar alterações (git push) ao repositório, ela precisa ser colaboradora. No repositório, vá em Settings → Collaborators e clique em Add people.

Dica

Busque pelo usuário ou e-mail do GitHub. A pessoa recebe um convite por e-mail e só tem acesso depois de aceitar.

Lista os arquivos que o Git não deve enviar. Na pasta do projeto:

> ni .gitignore

Abra o arquivo e cole:

# Ambiente virtual
.venv/

# Cache do Python
__pycache__/
*.pyc

# Banco de dados local
db.sqlite3
db.sqlite3-journal

# Variáveis de ambiente (senhas, chaves)
.env

# Arquivos gerados pelo Django
media/
staticfiles/

# Logs
*.log

# Editores
.vscode/
.idea/

Atenção

Crie o .gitignore antes do git init e do primeiro commit, assim a .venv nunca é enviada.

Na pasta do projeto, execute:

> git init
Initialized empty Git repository in C:/.../meu_projeto/.git/

O que acontece?

É criada a pasta oculta .git, onde o Git guarda o histórico do projeto.

# Adiciona todos os arquivos
> git add .

# Cria e adiciona o README
> ni README.md
> git add README.md

# Salva a versão
> git commit -m "first commit"

# Renomeia a branch para main
> git branch -M main

# Conecta ao repositório do GitHub
> git remote add origin https://github.com/seurepositorio

# Envia para o GitHub
> git push -u origin main

Atenção

Troque https://github.com/seurepositorio pelo endereço do repositório criado no Passo 10.

Primeiro commit pediu nome e e-mail?

Configure uma única vez:

  • git config --global user.name "Seu Nome"
  • git config --global user.email "seu@email.com"

Sempre que alterar o projeto:

# Confere em qual branch está (marcada com *)
> git branch

# Salva e envia
> git add .
> git commit -m "descreva a alteração"
> git push
# Baixa o projeto
> git clone https://github.com/seurepositorio
> cd seurepositorio

# Busca as branches do GitHub
> git fetch origin

# Lista as branches
> git branch -a

# Muda para uma branch
> git switch nome-da-branch

# Atualiza com a última versão
> git pull

Como usar as branches do repositório

O git branch -a mostra as branches do GitHub como remotes/origin/nome. Para usar, digite só o nome, sem o origin/:

  • git switch nome-da-branch, cria a branch local ligada à origin/nome-da-branch.
  • Depois disso, git pull e git push funcionam direto nela.
