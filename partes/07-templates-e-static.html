courses/templates/courses/
Templates do app. O Django encontra essa pasta sozinho (APP_DIRS = True).
courses/static/courses/
CSS, JS e imagens do app. Também é encontrada sozinha, sem configurar nada.
urls.py
Rotas do app. O startapp não cria, crie o arquivo vazio.

Por que repetir o nome do app?

O Django junta os templates e statics de todos os apps num lugar só. Se dois apps tiverem um style.css, um sobrescreve o outro. A subpasta com o nome do app evita isso: templates/courses/ e static/courses/.

✓ Conferir o static

O settings.py já vem com a linha abaixo, não precisa mudar:

STATIC_URL = 'static/'

E em produção?

Com DEBUG = True o runserver entrega os statics sozinho. No deploy se usa STATIC_ROOT e python manage.py collectstatic, veremos depois.

1 Configurar o settings.py

Abaixo do STATIC_URL, adicione:

STATIC_URL = 'static/'

MEDIA_URL = 'media/'
MEDIA_ROOT = BASE_DIR / 'media'
MEDIA_URL
Endereço dos arquivos no navegador: 127.0.0.1:8000/media/...
MEDIA_ROOT
Pasta do computador onde os arquivos são salvos. BASE_DIR é a pasta do projeto, a mesma do manage.py.

2 Liberar a pasta media nas rotas

Diferente do static, o runserver não entrega o media sozinho. Adicione no urls.py do projeto:

from django.conf import settings
from django.conf.urls.static import static
from django.contrib import admin
from django.urls import path

urlpatterns = [
    path('admin/', admin.site.urls),
]

urlpatterns += static(settings.MEDIA_URL, document_root=settings.MEDIA_ROOT)
static(...)
Cria a rota que entrega os arquivos de MEDIA_ROOT no endereço MEDIA_URL.
+=
Junta essa rota à lista urlpatterns que já existe, sem apagar as outras.

Só no desenvolvimento

O static(...) só funciona com DEBUG = True. Em produção, quem entrega o media é o servidor web, veremos depois.

? Onde entram os campos de arquivo

O material e a image do Course, criados no passo 17, guardam os arquivos em MEDIA_ROOT, na subpasta do upload_to. No banco fica só o caminho do arquivo.

✓ Testar no admin

  1. Rode o servidor e abra um curso no /admin.
  2. Em Material, envie um PDF. Em Imagem, envie uma imagem. Salve.
  3. Abra o curso de novo e clique no link do arquivo, ele abre em 127.0.0.1:8000/media/courses/materials/...
