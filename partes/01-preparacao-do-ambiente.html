Os passos 1 a 4 em vídeo.

  1. Abra o Explorador de Arquivos (Win + E).
  2. Crie uma nova pasta.
  3. Dê um nome e pressione Enter.

Dica

Sem espaços ou acentos: meu_projeto

  1. Abra o terminal dentro da pasta do projeto.
  2. Execute o comando:
> python -m venv .venv

Dica

A pasta .venv guarda as bibliotecas só deste projeto.

A Automático, VS Code

A extensão Python ativa a .venv sozinha ao abrir um novo terminal.

B Manual

> .venv\Scripts\Activate.ps1
> .venv\Scripts\activate

! Erro de permissão no PowerShell?

Ajuste a política de execução do Windows:

> Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
> Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

Ainda com problema?

Use o CMD em vez do PowerShell.

> .venv\Scripts\activate.bat

Funcionou?

O terminal passa a mostrar (.venv) no início da linha.

Com a (.venv) ativa, execute:

> python.exe -m pip install --upgrade pip
> pip install django
> pip install django-jazzmin==3.0.1
> pip install pillow
django
O framework.
django-jazzmin
Tema visual para o painel admin.
pillow
Biblioteca de imagens, exigida pelo Django para usar ImageField (a imagem do curso, no passo 17). Site oficial: python-pillow.github.io

Atenção

Use a versão 3.0.1 do Jazzmin, versões mais novas estão com problemas.

# Versão do Python
> python --version

# Versão do Django
> django-admin --version

# Versão do Jazzmin
> pip show django-jazzmin

# Versão do Pillow
> pip show pillow

# Todas as bibliotecas instaladas
> pip list

A alternativa com o uv em vídeo.

O uv substitui os passos 2, 3 e 4: cria a .venv, instala as bibliotecas e anota tudo em arquivos, com poucos comandos.

Site oficial

docs.astral.sh/uv

1 Instalar o uv

> powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

Feche e abra o terminal, depois confira:

> uv --version

2 Iniciar o projeto

Dentro da pasta do projeto, execute:

> uv init
meu_projeto/
├── .git/
├── .gitignore
├── .python-version
├── main.py
├── pyproject.toml
└── README.md
.git/
O uv init já roda o git init, não precisa fazer o passo 12.
.gitignore
Já vem ignorando a .venv. Complete com o conteúdo do passo 11.
.python-version
Versão do Python que o projeto usa.
main.py
Arquivo de exemplo, pode apagar.
pyproject.toml
Ficha do projeto: nome, versão do Python e bibliotecas.
README.md
Descrição do projeto, aparece na página do GitHub.

3 Adicionar as bibliotecas

> uv add django pillow
> uv add django-jazzmin==3.0.1

O primeiro comando instala duas bibliotecas de uma vez, o django e o pillow. Basta separar os nomes com espaço.

Sem uv venv

O uv add cria a .venv sozinho e instala as bibliotecas. Não precisa rodar uv venv, uv lock nem uv sync.

✓ Arquivos novos

Depois do primeiro uv add, aparecem dois itens na pasta:

meu_projeto/
├── .git/
├── .venv/
├── .gitignore
├── .python-version
├── main.py
├── pyproject.toml
├── README.md
└── uv.lock
.venv/
O ambiente virtual, igual ao do passo 2. Fica fora do Git.
uv.lock
Anota a versão exata de cada biblioteca instalada, inclusive as que o Django puxa junto (asgiref, sqlparse, tzdata). É ele que permite recriar a mesma .venv em outro computador.

Atenção

O uv.lock vai para o Git, mas não edite à mão. O uv add e o uv remove atualizam ele sozinhos.

4 Entendendo o pyproject.toml

[project]
name = "meu-projeto"
version = "0.1.0"
description = "Add your description here"
readme = "README.md"
requires-python = ">=3.13"
dependencies = [
    "django>=6.1.2",
    "django-jazzmin==3.0.1",
    "pillow>=13.0.0",
]
requires-python
>=3.13 quer dizer Python 3.13 ou mais novo.
dependencies
Lista das bibliotecas do projeto, o uv add escreve aqui. Você não edita à mão.
>=6.1.2
Versão mínima. Aceita a 6.1.2 ou qualquer uma mais nova.
==3.0.1
Versão exata. Só aceita a 3.0.1.
pillow
Biblioteca de imagens, exigida pelo Django para usar ImageField.

pyproject.toml x uv.lock

O pyproject.toml diz o que o projeto aceita (django>=6.1.2). O uv.lock diz o que foi instalado (exatamente django==6.1.2).

5 Rodar comandos

Coloque uv run na frente do comando e ele roda direto com a .venv do projeto, sem precisar ativar:

> uv run django-admin startproject app .
> uv run python manage.py runserver

Adeus erro de permissão

Como não roda o Activate.ps1, o PowerShell não bloqueia nada. Não precisa mexer no Set-ExecutionPolicy do passo 3.

Prefere ativar?

A ativação do passo 3 funciona igual. Com a (.venv) ativa, use os comandos do tutorial normalmente, sem o uv run.

6 Outros comandos

uv sync
Recria a .venv a partir do uv.lock. Use depois de clonar em outro computador, no lugar dos passos 2 a 4.
uv lock
Regera o uv.lock. Só é preciso se você editou o pyproject.toml à mão.
uv remove nome
Desinstala a biblioteca e tira do pyproject.toml.
uv tree
Mostra as bibliotecas instaladas e do que cada uma depende.
