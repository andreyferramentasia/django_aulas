A ListView é uma view genérica do Django: busca os registros do model e entrega para o template, sem precisar escrever a consulta.

1 A view

from django.views.generic import ListView
from courses.models import Course  # troque courses pelo nome do seu app


class CourseListView(ListView):
    model = Course
    template_name = "courses/course_list.html"
    context_object_name = "courses"
    paginate_by = 10
model
Model listado. A view faz Course.objects.all(), respeitando o ordering do Meta.
template_name
Template usado. Opcional, o padrão já é courses/course_list.html, mas deixar escrito fica mais claro.
context_object_name
Nome da lista no template. Sem ele, use course_list ou object_list.
paginate_by
Quantos registros por página. Opcional.

2 As rotas do app

from django.urls import path
from courses.views import CourseListView  # troque courses pelo nome do seu app

app_name = "courses"

urlpatterns = [
    path("listar/", CourseListView.as_view(), name="course_list"),
]

3 Incluir no projeto

from django.conf import settings
from django.conf.urls.static import static
from django.contrib import admin
from django.urls import path, include

urlpatterns = [
    path('admin/', admin.site.urls),
    path('courses/', include('courses.urls')),  # troque courses pelo nome do seu app
]

urlpatterns += static(settings.MEDIA_URL, document_root=settings.MEDIA_ROOT)
as_view()
Transforma a classe em uma view que o path entende. Sempre necessário em views de classe.
name
Apelido da rota, usado nos links: {% url 'courses:course_list' %}.
app_name
Namespace do app, evita conflito se outro app tiver uma rota com o mesmo name.
include
Liga as rotas do app às rotas do projeto.
'courses/'
Prefixo de todas as rotas do app. O "listar/" do app vira /courses/listar/, e as próximas seguem o mesmo padrão: /courses/criar/, /courses/3/editar/, /courses/3/deletar/.

E a página inicial?

Com o prefixo, nenhuma rota responde em http://127.0.0.1:8000/, então ela mostra Page not found (404). É normal: a lista fica em /courses/listar/.

{% block title %}Cursos{% endblock %}

{% block content %}

        {% endfor %}

    {% if is_paginated %}
        <nav class="d-flex align-items-center gap-2">
            {% if page_obj.has_previous %}

            {% endif %}
            <span class="text-muted small">Página {{ page_obj.number }} de {{ page_obj.paginator.num_pages }}</span>
            {% if page_obj.has_next %}
                <a href="{% querystring page=page_obj.next_page_number %}" class="btn btn-sm btn-outline-primary">Próxima</a>
            {% endif %}
        </nav>
    {% endif %}
{% endblock %}

? Entendendo o código

{% extends "base.html" %}
A página usa o base.html do extra Criar o template base: Bootstrap, CSS, navbar, sidebar e footer vêm de lá. Aqui fica só o conteúdo, dentro do {% block content %}.
O CSS
O style.css é carregado no base.html, depois do Bootstrap, então o que você escrever nele vale para todas as páginas.
{{ ... }}
Exibe um valor. {% ... %} executa uma lógica (for, if).
{% empty %}
Mostrado quando a lista está vazia.
page_obj
Criado pelo paginate_by, controla a navegação entre páginas.
{% querystring %}
Monta o link da página (?page=2) mantendo os outros parâmetros da URL, como uma busca. Disponível a partir do Django 5.1.

✓ Resultado esperado

> python manage.py runserver

Acesse http://127.0.0.1:8000/courses/listar/ e veja os cursos cadastrados no admin.

TemplateDoesNotExist?

Confira o caminho: templates/courses/course_list.html, dentro do app, e se o app está no INSTALLED_APPS. Se o erro falar do base.html, confira o "DIRS" no settings.py e se a pasta templates/ está na raiz do projeto.

CSS não carregou?

Reinicie o runserver após criar a pasta static/ e force a atualização do navegador com Ctrl + F5.

A ListView mostra vários cursos. A DetailView mostra um, buscada pelo pk que vem na URL.

1 A view

from django.views.generic import ListView, DetailView
from courses.models import Course  # troque courses pelo nome do seu app


class CourseListView(ListView):
    ...


class CourseDetailView(DetailView):
    model = Course
    template_name = "courses/course_detail.html"
    context_object_name = "course"
model
Model buscado. A view faz Course.objects.get(pk=...) com o pk da URL. Se não existir, dá erro 404.
context_object_name
Nome do curso no template. Sem ele, use course ou object.

2 A rota

from django.urls import path
from courses.views import CourseListView, CourseDetailView  # troque courses pelo nome do seu app

app_name = "courses"

urlpatterns = [
    path("listar/", CourseListView.as_view(), name="course_list"),
    path("<int:pk>/ver/", CourseDetailView.as_view(), name="course_detail"),
]
<int:pk>
Pega o número da URL e entrega para a view como pk. Em /courses/3/ver/, o pk é 3.

3 O template

{% extends "base.html" %}

{% block title %}Curso{% endblock %}

{% block content %}
    <h1>{{ course.name }}</h1>
    {% if course.image %}
        <img src="{{ course.image.url }}" alt="{{ course.name }}" class="img-fluid rounded mb-3">
    {% endif %}
    <p>Professor: {{ course.teacher }}</p>
    <p>Período: {{ course.get_period_display }}</p>
    <p>Carga horária: {{ course.workload }} h</p>
    <p>{{ course.description }}</p>
    {% if course.material %}
        <a href="{{ course.material.url }}" class="btn btn-outline-primary" target="_blank">Baixar material</a>
    {% endif %}
    {# troque courses pelo nome do seu app #}
    <a href="{% url 'courses:course_list' %}" class="btn btn-secondary">Voltar</a>
{% endblock %}
{{ course.teacher }}
O professor ligado pela ForeignKey. Aparece o texto do __str__ do Person: nome e sobrenome.
{{ course.get_period_display }}
Mostra "Matutino" em vez de "M", como visto no passo 17. No template vai sem os parênteses.
{{ course.image.url }}
O endereço do arquivo em /media/. O .url só funciona por causa da configuração do media na parte Templates, Static e Media.
{% if course.image %}
A imagem e o material são opcionais (blank=True). Sem o if, um curso sem arquivo dá erro ao pedir o .url.

4 O botão na lista

No course_list.html, cada curso ganha um botão Ver, com as classes do Bootstrap:

{% for course in courses %}
    <li>
        {{ course.name }}
        {# troque courses pelo nome do seu app #}
        <a href="{% url 'courses:course_detail' course.pk %}" class="btn btn-sm btn-secondary">Ver</a>
    </li>
{% empty %}
    <li>Nenhum curso cadastrado.</li>
{% endfor %}

✓ Resultado esperado

Na lista, clique em Ver ao lado de um curso e veja a página dele em http://127.0.0.1:8000/courses/1/ver/. Um pk que não existe dá 404.

E a permissão?

Ainda não existem contas de usuário, então a página fica aberta. Na parte Protegendo as Views, ela recebe a mesma permissão da lista: view_course.
