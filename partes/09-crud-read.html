A ListView é uma view genérica do Django: busca os registros do model e entrega para o template, sem precisar escrever a consulta.

1 A view

from django.views.generic import ListView
from nome_do_seu_app.models import Person


class PersonListView(ListView):
    model = Person
    template_name = "nome_do_seu_app/person_list.html"
    context_object_name = "people"
    paginate_by = 10
model
Model listado. A view faz Person.objects.all(), respeitando o ordering do Meta.
template_name
Template usado. Opcional, o padrão já é nome_do_seu_app/person_list.html, mas deixar escrito fica mais claro.
context_object_name
Nome da lista no template. Sem ele, use person_list ou object_list.
paginate_by
Quantos registros por página. Opcional.

2 As rotas do app

from django.urls import path
from nome_do_seu_app.views import PersonListView

app_name = "nome_do_seu_app"

urlpatterns = [
    path("pessoas/", PersonListView.as_view(), name="person_list"),
]

3 Incluir no projeto

from django.contrib import admin
from django.urls import path, include

urlpatterns = [
    path('admin/', admin.site.urls),
    path('', include('nome_do_seu_app.urls')),
]
as_view()
Transforma a classe em uma view que o path entende. Sempre necessário em views de classe.
name
Apelido da rota, usado nos links: {% url 'nome_do_seu_app:person_list' %}.
app_name
Namespace do app, evita conflito se outro app tiver uma rota com o mesmo name.
include
Liga as rotas do app às rotas do projeto.

1 A página da lista

{% extends "base.html" %}

{% block title %}Pessoas{% endblock %}

{% block content %}
    <h1>Pessoas</h1>

    <ul>
        {% for person in people %}
            <li>{{ person.first_name }} {{ person.last_name }}</li>
        {% empty %}
            <li>Nenhuma pessoa cadastrada.</li>
        {% endfor %}
    </ul>

    {% if is_paginated %}
        <nav class="d-flex align-items-center gap-2">
            {% if page_obj.has_previous %}
                <a href="{% querystring page=page_obj.previous_page_number %}" class="btn btn-sm btn-outline-primary">Anterior</a>
            {% endif %}
            <span class="text-muted small">Página {{ page_obj.number }} de {{ page_obj.paginator.num_pages }}</span>
            {% if page_obj.has_next %}
                <a href="{% querystring page=page_obj.next_page_number %}" class="btn btn-sm btn-outline-primary">Próxima</a>
            {% endif %}
        </nav>
    {% endif %}
{% endblock %}

? Entendendo o código

{% extends "base.html" %}
A página usa o base.html do extra Criar o template base: Bootstrap, CSS, navbar, sidebar e footer vêm de lá. Aqui fica só o conteúdo, dentro do {% block content %}.
O CSS
O style.css é carregado no base.html, depois do Bootstrap, então o que você escrever nele vale para todas as páginas.
{{ ... }}
Exibe um valor. {% ... %} executa uma lógica (for, if).
{% empty %}
Mostrado quando a lista está vazia.
page_obj
Criado pelo paginate_by, controla a navegação entre páginas.
{% querystring %}
Monta o link da página (?page=2) mantendo os outros parâmetros da URL, como uma busca. Disponível a partir do Django 5.1.

✓ Resultado esperado

> python manage.py runserver

Acesse http://127.0.0.1:8000/pessoas/ e veja as pessoas cadastradas no admin.

TemplateDoesNotExist?

Confira o caminho: templates/nome_do_seu_app/person_list.html, dentro do app, e se o app está no INSTALLED_APPS. Se o erro falar do base.html, confira o "DIRS" no settings.py e se a pasta templates/ está na raiz do projeto.

CSS não carregou?

Reinicie o runserver após criar a pasta static/ e force a atualização do navegador com Ctrl + F5.

A ListView mostra várias pessoas. A DetailView mostra uma, buscada pelo pk que vem na URL.

1 A view

from django.views.generic import ListView, DetailView
from nome_do_seu_app.models import Person


class PersonListView(ListView):
    ...


class PersonDetailView(DetailView):
    model = Person
    template_name = "nome_do_seu_app/person_detail.html"
    context_object_name = "person"
model
Model buscado. A view faz Person.objects.get(pk=...) com o pk da URL. Se não existir, dá erro 404.
context_object_name
Nome da pessoa no template. Sem ele, use person ou object.

2 A rota

from django.urls import path
from nome_do_seu_app.views import PersonListView, PersonDetailView

app_name = "nome_do_seu_app"

urlpatterns = [
    path("pessoas/", PersonListView.as_view(), name="person_list"),
    path("pessoas/<int:pk>/", PersonDetailView.as_view(), name="person_detail"),
]
<int:pk>
Pega o número da URL e entrega para a view como pk. Em /pessoas/3/, o pk é 3.

3 O template

{% extends "base.html" %}

{% block title %}Pessoa{% endblock %}

{% block content %}
    <h1>{{ person.first_name }} {{ person.last_name }}</h1>
    <p>Nome: {{ person.first_name }}</p>
    <p>Sobrenome: {{ person.last_name }}</p>
    <a href="{% url 'nome_do_seu_app:person_list' %}" class="btn btn-secondary">Voltar</a>
{% endblock %}

4 O botão na lista

No person_list.html, cada pessoa ganha um botão Ver, com as classes do Bootstrap:

{% for person in people %}
    <li>
        {{ person.first_name }} {{ person.last_name }}
        <a href="{% url 'nome_do_seu_app:person_detail' person.pk %}" class="btn btn-sm btn-secondary">Ver</a>
    </li>
{% empty %}
    <li>Nenhuma pessoa cadastrada.</li>
{% endfor %}

✓ Resultado esperado

Na lista, clique em Ver ao lado de uma pessoa e veja a página dela em http://127.0.0.1:8000/pessoas/1/. Um pk que não existe dá 404.

E a permissão?

Ainda não existem contas de usuário, então a página fica aberta. Na parte Protegendo as Views, ela recebe a mesma permissão da lista: view_person.
