A UpdateView é a view genérica de edição. É quase igual à CreateView: a diferença é que busca o registro pelo pk da URL e preenche o formulário com ele.

1 A view

from django.views.generic import ListView, CreateView, UpdateView
...


class CourseUpdateView(UpdateView):
    model = Course
    form_class = CourseForm
    # troque courses pelo nome do seu app
    template_name = "courses/course_form_update.html"
    context_object_name = "course"
    success_url = reverse_lazy("courses:course_list")
template_name
Página da edição, course_form_update.html, criada no próximo passo.
context_object_name
Nome do registro no template: {{ course }}, usado no título "Editar Python Básico".

2 A rota

from django.urls import path
# troque courses pelo nome do seu app
from courses.views import CourseListView, CourseCreateView, CourseUpdateView

app_name = "courses"

urlpatterns = [
    path("listar/", CourseListView.as_view(), name="course_list"),
    path("criar/", CourseCreateView.as_view(), name="course_create"),
    path("<int:pk>/editar/", CourseUpdateView.as_view(), name="course_update"),
]
<int:pk>
Parte variável da URL: o id do curso. Em /courses/3/editar/ a view edita o curso de id 3.

2 Link de edição na lista

No course_list.html, adicione um link em cada curso:

{% for course in courses %}
    <li>
        {{ course.name }}
        {# troque courses pelo nome do seu app #}
        <a href="{% url 'courses:course_update' course.pk %}" class="btn btn-sm btn-primary">Editar</a>
    </li>
{% empty %}
    <li>Nenhum curso cadastrado.</li>
{% endfor %}
{% url '...' course.pk %}
Monta a URL da rota passando o id, ex.: /courses/3/editar/.
Por que pega o id certo?
O link está dentro do {% for course in courses %}. A cada volta do for, course é um curso diferente, então course.pk muda junto: no curso de id 1 o link vira /courses/1/editar/, no de id 2 vira /courses/2/editar/, e assim por diante. Cada linha da lista ganha o link do seu próprio curso. Fora do for, course não existe e o link não funciona.

✓ Resultado esperado

Na lista, clique em Editar. O formulário abre preenchido e com o título "Editar". Altere o nome, salve e volte para a lista atualizada.

Arquivos na edição

Nos campos Material e Imagem, o formulário mostra Atualmente: ... com o arquivo salvo. Deixe vazio para manter o arquivo, envie outro para trocar, ou marque Limpar para remover.

Erro 404?

Não existe curso com aquele id. Confira o número na URL ou cadastre cursos antes.
