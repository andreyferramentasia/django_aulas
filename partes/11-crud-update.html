A UpdateView é a view genérica de edição. É quase igual à CreateView: a diferença é que busca o registro pelo pk da URL e preenche o formulário com ele.

1 A view

from django.views.generic import ListView, CreateView, UpdateView
...


class PersonUpdateView(UpdateView):
    model = Person
    form_class = PersonForm
    template_name = "nome_do_seu_app/person_form_update.html"
    context_object_name = "person"
    success_url = reverse_lazy("nome_do_seu_app:person_list")
template_name
Página da edição, person_form_update.html, criada no próximo passo.
context_object_name
Nome do registro no template: {{ person }}, usado no título "Editar Fulano".

2 A rota

from django.urls import path
from nome_do_seu_app.views import PersonListView, PersonCreateView, PersonUpdateView

app_name = "nome_do_seu_app"

urlpatterns = [
    path("pessoas/", PersonListView.as_view(), name="person_list"),
    path("pessoas/nova/", PersonCreateView.as_view(), name="person_create"),
    path("pessoas/<int:pk>/editar/", PersonUpdateView.as_view(), name="person_update"),
]
<int:pk>
Parte variável da URL: o id da pessoa. Em /pessoas/3/editar/ a view edita a pessoa de id 3.

Documentação

docs.djangoproject.com/pt-br/stable/ref/class-based-views/generic-editing

Igual ao cadastro, mas o formulário já abre preenchido com os dados da pessoa.

2 Link de edição na lista

No person_list.html, adicione um link em cada pessoa:

{% for person in people %}
    <li>
        {{ person.first_name }} {{ person.last_name }}
        <a href="{% url 'nome_do_seu_app:person_update' person.pk %}" class="btn btn-sm btn-primary">Editar</a>
    </li>
{% empty %}
    <li>Nenhuma pessoa cadastrada.</li>
{% endfor %}
{% url '...' person.pk %}
Monta a URL da rota passando o id, ex.: /pessoas/3/editar/.
Por que pega o id certo?
O link está dentro do {% for person in people %}. A cada volta do for, person é uma pessoa diferente, então person.pk muda junto: na pessoa de id 1 o link vira /pessoas/1/editar/, na de id 2 vira /pessoas/2/editar/, e assim por diante. Cada linha da lista ganha o link da sua própria pessoa. Fora do for, person não existe e o link não funciona.

✓ Resultado esperado

Na lista, clique em Editar. O formulário abre preenchido e com o título "Editar". Altere o nome, salve e volte para a lista atualizada.

Erro 404?

Não existe pessoa com aquele id. Confira o número na URL ou cadastre pessoas antes.
